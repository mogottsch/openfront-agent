Strategy gates in one glance

No focus yetPrompt asks Jev to weigh tribe gold, wilderness and timely affordable expansion. No fixed reserve percentage.
Focused tribe aliveSame target or wait; no new attack front. Lost border → wilderness reconnection allowed. Builds remain possible.
Bordering tribes remainNation attacks withheld. Otherwise Jev judges a credible full conquest; humans are not categorically withheld.
Reinforce or regrowTribe: wait / 10% / 20%. Other attack targets: offered 10–50%. No automatic escalation or answer replacement.

    Other concrete data contracts
    

    Tribe focus · observation, model projection, and gated menu
    Raw observation
    Projected state + strategy gate
    Reference time = decision observation before inference, not intent emission. Focus clears on authoritative death, not an exhausted attack or missing border.
    

    Neighbor City / Post inventory · same-tick optional field
    Completed and constructing instance counts are separate from levels. Missing field = unknown, not zero. No positions, terrain, route, range coverage or conquest prediction.
    

    Territory-loss threshold + single-opponent border cue · derived, not gates
    Tile-loss threshold
    For T>0, code derives max(1,T−99); zero territory is null. Assumes no intervening gains/losses. At 1–100 tiles, one successful enemy capture may trigger conquest/remnant cleanup; it does not predict a successful capture.
    Border contacts
    all_edges_touch_one_unallied_player describes a snapshot where every player-border edge touches one unallied neighbor. It is not an enclosure or cleanup-schedule verdict. Both facts inform Jev but never filter or replace an action.
    

    Raw Hybrid input envelope · browser → local sidecar
    Local Start authorization is carried separately; provider credentials stay server-side. These examples contain no real player snapshot or token.
