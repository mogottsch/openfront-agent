# Project workflow

- After each small, coherent iteration, run relevant checks, commit the changes, and push to this repository's configured origin. Moritz explicitly requested this workflow.
- Keep commits focused. Do not force-push or publish failing/untested changes as verified work.
- This is a public repository. Never commit API keys, secret files, `.env` files, or generated run logs. Keep TypeSafe credentials in the local Node service, not browser code.
- Track OpenFront integration source in `integration/` and installation logic in `scripts/`. `../OpenFrontIO` is a separate upstream checkout; do not push there. Update the integration source here, then use `npm run install:bridge` to deploy it locally.
- Moritz has now authorized autonomous local development of a hybrid Jev + GitHub Copilot agent intended to beat the strongest native OpenFront bots, including spatial understanding, buildings, upgrades and strategic planning. Expand observations and actions in small, independently tested, clearly versioned slices; do not mistake proposed interfaces in `docs/hybrid-agent-design.html` for deployed features. Local solo remains the only approved execution environment; do not act in multiplayer or push to upstream OpenFront.
- Current tested land policy is `land-strategy-v4.5.2-neighbor-structure-facts`: optional same-snapshot neighbor City/Post inventory separates completed/constructing counts and completed levels; missing means unknown, not zero. Counts do not imply geometry/protection/future strength or conquest probability; no full-map scan runs in the 1Hz observation loop. Transparent user-authored pre-inference gates retain one still-alive tribe focus, prohibit new fronts during it (except disclosed lost-border wilderness reconnection), and withhold nations while unallied bordering tribes remain. Factual progress counts emitted intents, not accepted/completed pushes; its reference tick/tiles are the PRE-INFERENCE decision-observation snapshot, not emission time. A bounded **v4.5.1** 90-real-response native Easy Europe/Compact land-only headless run conquered one tribe with three 20% sends and collected **7,350 engine-verified gold**. It stopped after 90 game seconds with 9,919 tiles; **censored, not a win**. The headless engine pauses during inference. This is not a controlled comparison with the earlier 400-tribe browser failure; no Easy/higher model win or real model City/Post/boat outcome is established. Historical notes below remain historical.
- The earlier committed land baseline was neutral v3; the expanded neutral v3.1 menu was uncommitted. The v4.2 land experiment adds incoming/outgoing attack observations, a tribe commitment ceiling of 20%, and a prompt based on Moritz's reviewed land priorities. Earlier v4 play repeatedly depleted troops; v4.1 overcorrected and waited excessively during a running push; v4.2 improved a paired 30-second Impossible-nation opening but **lost a complete five-minute Onion/Impossible match** after capturing the 6,505-tile starting island and exhausting land options at second 46. Port-free boat crossing is source-verified. Worker-checked City, coastal boat and Defense Post candidates plus normal guarded intents are available behind separate local-only opt-ins; a real Jev-selected City/boat/Post intent and game outcome have **not** been observed. Controlled two-boat scripts also lost 0/3 full Impossible seeds. Recent TypeSafe inference requests sometimes returned HTTP 529 and were stopped or discarded. Fixed genuine-engine Jev probes (flat and decomposed) returned both wait and boat choices but emitted no intents; never re-label a mocked choice or probe as live gameplay. Do not silently replace Jev choices with heuristics or reinstate the old numeric 30% reserve rule. Cadence (one second start-to-start, single-flight), arithmetic, candidate coverage, and real-game legality belong to the harness. Differentiate observed game results from mocked tests and real model judgments.
- The Copilot connector uses the pinned official backend SDK. GitHub returned typed authorization 403 to an ambient login; the sidecar now requires an explicit server-only `COPILOT_GITHUB_TOKEN` with Copilot Requests permission, suppresses ambient token fallback, and leaves the planner disabled when missing. Keep both providers' credentials server-side. Any new model must return structured, validated planning or bounded candidate IDs, never arbitrary code or client-executed tool calls. Seeded actual-engine matches, including Impossible native bots, are required before claiming competitive performance.

## Checks

- `npm test` — dependency-free agent tests; no real API calls.
- After bridge changes, install it into the sibling checkout, run `npm run test:bridge` here, then `npx tsc --noEmit` and relevant OpenFront tests there (see `README.md`).
- For browser/gameplay changes, use a short, explicitly bounded local solo smoke test. Report the difference between mock tests, real model decisions, emitted intents, and observed game outcomes.
- Both the local game and the Jev sidecar may already be running. Check before starting duplicates. No API requests should occur until the user explicitly starts the controller.
